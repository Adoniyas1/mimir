# Wake word files

Drop your trained "Mimir" Porcupine keyword files here:

- `mimir_mac.ppn` — for macOS
- `mimir_windows.ppn` — for Windows

Train one for free at https://console.picovoice.ai (Porcupine → Create a
wake word → type "Mimir" → pick your target platform). Without a file here
and a Picovoice AccessKey in Settings, the wake word is simply disabled and
push-to-talk (the mic button) still works fully offline.
